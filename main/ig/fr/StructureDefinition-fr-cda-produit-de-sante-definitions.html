0. FRCDAManufacturedProductPharm
Définition

ManufacturedProduct CDA dont le manufacturedMaterial est typé FRCDAMaterialPharm (matériau pharmaceutique enrichi).


Base definition for all types defined in FHIR type system.

CourtCDA - Produit manufacturé pharmaceutiqueBase for all types and resources
