Modèle logique: CDA - FR Instructions au patient

URL officielle: https://interop.esante.gouv.fr/ig/cda/document-core/StructureDefinition/fr-cda-instructions-au-patient Version: 0.1.0
Draft à partir de 2026-08-03 Nom computable: FRCDAInstructionsAuPatient

Entrée FR-Instructions-au-patient: IHE-PCC - Patient-Medication-Instructions. Cette entrée permet d’enregistrer des instructions au patient :

  • sous forme textuelle uniquement (c’est notamment le cas pour les prescriptions de médica-ments) ;
  • sous forme codée : chaque instruction est alors codée dans une sous-entrée FR-Instruction-au-patient (c’est notamment le cas pour les prescriptions d’examens de biologie médicale).

Utilisations:

  • Utilise ce/t/te Profil de modèle logique: CDA - FR Item plan traitement, CDA - FR Traitement dispense, CDA - FR Traitement prescrit and CDA - FR Traitement

Vous pouvez également vérifier les usages dans le FHIR IG Statistics
